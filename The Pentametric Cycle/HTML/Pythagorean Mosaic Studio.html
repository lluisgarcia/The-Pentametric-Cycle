Pythagorean Mosaic Studio

Every tile comes from your list of areas: a square has side √area, a circle has radius √(area/π). Choose which tiles to use, pick a pattern, a shape and a palette, then repeat the result as a mosaic and save it as an image.

Lluís' Tesserae (LT) - (The Tessera Sequence)

LT(n) = ( n² + 4·(26m − 5m²)/24 ) / 5, where m = (4n²) mod 10 and n starts at 0. Repeated values appear once, and an area of 0 is shown as nothing.

Type any numbers separated by commas (decimals use a dot; 0 is shown as nothing), or load a .txt or .csv file. They replace the Tessera Sequence while the box is ticked.
