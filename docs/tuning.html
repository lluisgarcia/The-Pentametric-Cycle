How to use the file

  

    
In a synthesizer that supports Scala tuning, load the .scl file from its tuning or microtuning menu. The scale is mapped onto the keyboard starting from the base key, and repeats every time it reaches its last step (the octave, or for the non-octave scale, its own period). The first line of the file starting with “!” is a comment; the next line is the description; then the number of steps; then each step as a ratio (like 3/2) or in cents (like 91.20).

    
The tetractys and Pythagorean scales follow directly from the consonances of the papers. The √10/3 and 13-cycle scales come from the exploratory pages and are offered as material for experiments.
